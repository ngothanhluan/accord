## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| existing target directory contents -> the orphan scan | Whatever is already under `.claude/skills/` or `.agents/skills/`, including directories accord did not create. |
| `config.yml` version string -> every repository-reading command | The pin decides whether a command runs at all. |

Absent surfaces: no authentication, no session, no network, no database, no untrusted input
parsed into executable form. Plan 06-01's register covers the write path itself; this plan
adds the read-and-report half.
