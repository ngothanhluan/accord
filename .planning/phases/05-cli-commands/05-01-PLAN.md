Land the whole CLI spine on one command: `accord lint` works end to end from any subdirectory,
in text and in JSON, with the 0/1/2 exit contract and the config.yml version pin.

pipeline once, on the simplest command, is what makes the remaining four commands additive
rather than architectural.

render/color.ts, the shared sandbox test helper, the rewritten binary spawn test, and the

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell to CLI argv | the developer's command line and cwd reach root resolution and the loader |
| filesystem to CLI | repository content (config.yml, ticket text) is untrusted input parsed and printed |
| CLI to child process | the CLI spawns git; argv reaches the operating system |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Elevation of Privilege | packages/cli/src/root.ts, packages/cli/src/load/fs.ts | high | mitigate | Spawn by binary name with a literal argument array and no shell option; enforced by the allowlist assertion in packages/cli/test/spawn-surface.test.ts (Task 3) |
| T-05-02 | Tampering | packages/cli/src/run.ts preflight | high | mitigate | The version pin is checked at the single preflight call site with no flag or environment-variable bypass (D-94, D-95); Task 2 asserts a mismatch exits 2 |
| T-05-03 | Information Disclosure | packages/cli/src/render/color.ts | low | mitigate | Colour is emitted only through styleText with the stream option, so no escape sequence reaches a redirected or piped stdout; asserted by the no-ANSI case in Task 1 |
| T-05-04 | Denial of Service | packages/cli/src/root.ts | low | accept | A hung git invocation blocks the CLI; execFileSync inherits no timeout. Accepted: git is already a hard precondition of the existing loader and the failure is visible to the operator |
| T-05-SC | Tampering | npm/pip/cargo installs | low | accept | This plan adds no dependency; commander 15.0.0 is already pinned in packages/cli/package.json and no package-manager install task exists in this phase |
</threat_model>
