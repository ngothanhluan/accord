## Phase Goal

**As a** BA or developer whose ticket lives in a repository, **I want to** run one pure function over the loaded snapshot and get every finding with file, line, rule id, level, and reason, rendered as text or JSON from one object, **so that** the CLI, CI, and any host show the same verdict.

(Derived from the ROADMAP Phase 3 Goal line, which is not written in user-story form; the story adds no scope.)

This is the tracer slice: one path through every layer the phase touches. `Finding` gains `level` (D-56); `RepoSnapshot` gains `files` (D-65); the loader fills it; the rule table exists with two real rules, one line-less error (`lint.id-mismatch`, D-34) and one line-bearing warning (`lint.test-tag-missing`, D-69); the engine merges loader findings (D-58), sorts, counts; `renderText` prints the D-60 line shape; the golden loop, the round-trip identity test, the barrel, and the bundle test all exist. Later plans add rows to `RULES` and rule functions to the group files; nothing structural changes after this plan.

Purpose: prove model, loader, engine, renderer, and test harness end-to-end before thirty rules are written against them.

Scope note: Task 1 touches 33 files, the heaviest task in the phase. It is accepted as the tracer slice on purpose: 16 of the files are generated goldens, 7 are one-word `Finding` to `LoadFinding` type edits, and splitting model from engine would leave the `files` and `level` changes without the golden loop that proves them end-to-end.
