2. `const doc = parseDocument(yaml, { schema: 'core', customTags: stringNumerics })`; when `doc.errors.length > 0` throw `Error('setFrontmatterKey: invalid YAML: ' + first message)`; when `!isMap(doc.contents)` throw `Error('setFrontmatterKey: frontmatter is not a mapping')`.
3. Build the value node: a string → `doc.createNode(value)` with `.type = Scalar.QUOTE_DOUBLE`; a boolean → `doc.createNode(value)` (plain); a string array → `doc.createNode(value)` as a `YAMLSeq` with `.flow = value.length === 0` and every item `.type = Scalar.QUOTE_DOUBLE` (D-44, D-45).
4. Locate `const items = doc.contents.items` and `const existing = items.find(p => isScalar(p.key) && p.key.value === key)`. When it exists: copy `comment`, `commentBefore`, and `spaceBefore` from the old value node onto the new node where set, then assign `existing.value = node` (so a trailing `# comment` on the key line survives — verify in the golden). 5. Return `'---\n' + doc.toString({ lineWidth: 0 }) + '---\n' + body`. `doc.toString()` ends with a newline; do not add another. The body is the split's `body` (already LF, no BOM). Never touch the body.
