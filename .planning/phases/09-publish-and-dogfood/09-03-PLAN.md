<objective>
`packages/cli/package.json` declares `files: ["dist", "README.md"]` and `packages/cli/README.md`
does not exist. The published package would therefore have a blank npm page — D-156 defect 1, and
the one defect of the four that has to be fixed before `0.1.0` rather than in the dogfood ticket,
because the file has to be in the tarball.

Purpose: a user who is told to run `npx --yes @accord-dev/accord` and lands on an empty registry
page has no way to find out what they installed. This is the discoverability half of ROADMAP
criterion 1.

The Claude's Discretion item settles the shape: generated by a script from the root `README.md` and
covered by a drift test, the same three-part pattern `packages/core/src/generated/templates.ts` and
`skills.ts` already use. Two hand-maintained READMEs drift, and npm cannot reach a file outside the
package folder.

Output: a generator, a committed artifact, a drift test, and one appended command in the root `gen`
script.

**This plan builds nothing.** 09-01 is Wave 1's sole owner of `packages/core/dist/` and
`packages/cli/dist/`: it rebundles them and runs the tests that read them. `dist/` is gitignored,
so `files_modified` and the wave guard cannot see the overlap — this paragraph is the declaration.
Everything below runs from `src/`: vitest transpiles TypeScript, and `npm run lint` and
`npm run typecheck` write nothing (`noEmit: true` in `tsconfig.base.json`). `npm pack --dry-run` reads the `files:` list, not the
bundle's contents, so it is safe beside a concurrent build. Task 2's suite is filtered to this
plan's own test file: the unfiltered `--project cli` run would execute `bin.test.ts` and
`new-ticket.test.ts` while 09-01 is mid-edit of both. 09-06 Task 1 runs the whole suite once the
wave has settled.
</objective>

    1. A first-line comment naming the source (`README.md` at the repo root), the output

    3. `.replace(/^\uFEFF/, '').replace(/\r\n/g, '\n')` on the text read from disk — strip BOM,

    followed by a blank line — or npmjs.com renders it as body text. Write exactly one trailing
    newline.

    **Link rewriting is out of scope for this task and is a D-156 ticket decision.** The root README
    links `docs/design.md` relatively, which resolves on GitHub and 404s on npmjs.com. Do not invent
    a rewrite here. Copy the source text through verbatim after the BOM/CRLF normalisation, and
    record the open point in the SUMMARY so the dogfood ticket in 09-08 can rule on it in its
    `## Plan`.

    Then append ` && node packages/cli/scripts/gen-readme.mjs` to the root `package.json`'s `gen`

    asymmetry is the point. `.gitattributes` gives a Windows checkout CRLF on the source, so

    prevent, and normalising neither would go red on `windows-latest` only.

    a message ending `run npm run gen`, the same string `templates.test.ts` uses.
