<surfaced_assumptions>
- **A-12 — the START marker alone decides "the block is already present".** D-142 says the block being
  present means skip; it does not say what a start marker with no end marker is. Taking the start marker
  alone as the predicate means a half-written or hand-edited block is left exactly as it is. The alternative
  — requiring both markers, and appending a second block when only the start is found — writes a duplicate
  block into a file whose owner was clearly mid-edit, which is the outcome D-130 was chosen to make
  impossible. Skip, and let a human resolve their own half-edit.
  *Alternative:* require both markers; append when the pair is incomplete.

- **A-13 — the report gains a third status word, `appended`.** D-133 says every path is marked created or
  skipped; D-142 names three dispositions, and an append is neither of the other two. Reporting an append as
  `created` would be false about a file that already existed, and as `skipped` would be false about a file
  that changed. The third word is the smaller inaccuracy — none.
  *Alternative:* two words, accepting that one of them is wrong on the append branch.

- **A-14 — the separator is derived from what the existing file ends with.** Empty file: the block alone.
  Ends with two or more newlines: the block appended with nothing added. Ends with exactly one newline: one
  newline, then the block. Ends with anything else: two newlines, then the block. CONTEXT.md does not settle
  this; the alternative is a fixed `'\n\n' +` prefix, which puts a stray blank line at the top of a file
  that was empty and two blank lines into a file that already ended well.

- **A-15 — the one rule line is `A ticket is not started before \`accord gate ready <id>\` passes.`** D-143
  fixes the content and leaves the wording to the planner. It names the command and stops — the same
  discipline SKILL-04 enforces on the skill definitions themselves (plan 07-06), so the pointer cannot be
  the one place accord restates a rule the CLI enforces.
</surfaced_assumptions>
