<objective>
The second half of gap 2, under owner ruling **GAP-2c**: three shipped ticket templates use a tracker
product as the example key for `tracker:` — `# tracker: { shortcut: "1234" }` at line 9 of
`ticket-build.md`, `ticket-maintain.md` and `epic.md` — while that word is deliberately excluded from
`DENIED` as ordinary English. That is an exception to a hard constraint living in a test helper's
docstring rather than in prose, which is the shape of exception the F-2 ruling rejected.

The owner ruled: reword the examples, keep the exclusion. The key becomes one `config.yml` actually
offers, so the word appears nowhere as a product name, no carve-out is needed, and the constraint stays
absolute.

The cost is a chain, and it is the chain 07-11 hit: the templates are code-generated into
`packages/core/src/generated/templates.ts`, a drift case binds that record to the directory file by
file, and one golden is a file snapshot of the rendered build template.

Purpose: a constraint with a written exception is one nobody can enforce later. Removing the need for
the exception is cheaper than defending it.
Output: three template lines, one regenerated record, one regenerated golden, and the README that
documents them.
</objective>
