<surfaced_assumptions>
- **A-20 — the examples keep the `accord/` folder and the code the gates resolve against, and drop the rest
  of what `init` writes.** `init` also emits `.github/workflows/accord.yml`, `AGENTS.md`, `CLAUDE.md`, and
  the skill copies. A workflow nested under `examples/build/` is never executed by GitHub (only the
  repository root's `.github/workflows/` runs), and committing rendered skill copies that this repository's
  own `accord skills sync` does not manage creates exactly the silent drift Phase 6 exists to prevent — the
  orphan scan and the marker-and-hash rule both stop at the repository root. The gates read `accord/` and
  the paths it references, which is what the examples keep.
  *Alternative:* commit everything `init` writes, and add the example copies to whatever later mechanism
  keeps rendered output in step.

**A-20 to A-23 apply to both example plans. 07-08 refers to them by number rather than restating them.**

- **A-21 — the short sha in both examples is the literal `1234567`, substituted by 07-08's CI job.** `gate done`
  compares `verified_commit` against the gated commit's sha, which cannot be known when the file is
  authored. `1234567` is the abbreviation of the `COMMIT` constant `gate.test.ts:26` already uses, so the
  core suite drives it by spreading `git` facts, and the CI job replaces that one token with the sandbox's
  real `git rev-parse --short HEAD` before invoking `gate done`.
  *Alternative:* generate the examples in CI instead of committing them, which means nobody can read one
  without running anything.

- **A-22 — the example configs carry the same version pin as everything else, so a version bump breaks the
  CI job until they are updated.** That is the pin working: D-95 makes a mismatch a hard refusal naming both
  versions and the fix. A bump that forgets the examples should be loud.
  *Alternative:* exempt the examples, and let them silently demonstrate a contract nobody is running.

- **A-23 — the example ticket prose is English.** The fixtures under `packages/core/test/fixtures/` are
  deliberately Vietnamese because they are also the non-ASCII round-trip test. The examples are documentation
  a reader learns the format from, so they read in the project's own language. The non-ASCII coverage stays
  where it is.

- **Skipped: `examples/README.md`.** Two directory names and two readable tickets are the explanation. Add
  one when a reader actually asks what distinguishes the profiles.
</surfaced_assumptions>
