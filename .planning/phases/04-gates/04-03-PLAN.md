`resolves(candidate, snapshot)`: let `key` be `normaliseKey(candidate)`; return true when `Object.hasOwn(snapshot.tests ?? {}, candidate)`, or `snapshot.tree.includes(key)`, or some path in `snapshot.tree` ends with `'/' + key`. Use `Object.hasOwn`, never the `in` operator, because an id named after an `Object.prototype` member otherwise reads as known — the defect the Phase 3 UAT closed in `load/junit.ts` and `lint/gherkin.ts`.

`unresolvedRefs(text, snapshot)`: the candidates that do not resolve, de-duplicated in first-appearance order.

`stripRefs(text, snapshot)`: split the text on `/\s+/`, drop each token whose stripped-and-position-trimmed form resolves, and rejoin the survivors with a single space. `normalise(text)`: lower-case with `toLowerCase()`, replace every character matching `/[\p{P}\p{S}]/gu` with a space, collapse `/\s+/` to a single space, and trim. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `verification.md` evidence text → the candidate tokeniser | Free prose, possibly large, written by an agent context; the layer whose whole job is to catch a fabricated citation |
| ticket `## Verification notes` text → the normaliser and the substring test | Free prose in any language, including Vietnamese; the last human check before QA |
| candidate token → `snapshot.tree` membership | A path-shaped string from untrusted content used only in a membership test, never to read anything |
